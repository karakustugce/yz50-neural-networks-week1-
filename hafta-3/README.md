# Hafta 3 — İlk Language Model

Bu klasör, YZ50 üçüncü hafta çalışması için ayrılmıştır.

## Teslim kapsamı

- [ ] İngilizce isimlerle dictionary ve tensor bigram sayımları
- [ ] 27×27 bigram tablosunun görselleştirilmesi
- [ ] Satır bazında olasılıklar ve isim örnekleme
- [ ] Negative log likelihood ve smoothing
- [ ] One-hot, logits, softmax ve gradient descent ile sinir ağı modeli
- [ ] Türkçe karakterleri içeren Türkçe isim verisiyle iki modelin yeniden çalıştırılması
- [ ] Üretilen Türkçe isim örnekleri ve loss sonuçları
- [ ] Açıklama videosu

> Program kuralı gereği uygulama kodu katılımcı tarafından yazılacaktır. Bu dosya yalnızca teslim kontrol listesidir.
